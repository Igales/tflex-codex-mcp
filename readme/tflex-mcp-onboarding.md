## 3. Архитектура

```
Perplexity (удалённый MCP-коннектор, Streamable HTTP, API Key)
   -> https://aerobics-washer-negotiate.ngrok-free.dev/mcp   (ngrok, Free, регион EU)
   -> SuperGateway 127.0.0.1:8765  (проверка ключа, белый список инструментов)
   -> node mcp\server.js           (MCP-сервер по stdio)
   -> http://127.0.0.1:38517/command  (HTTP-мост внутри T-FLEX)
   -> активный документ T-FLEX CAD
```

Ключевые параметры:

| Параметр | Значение |
| --- | --- |
| Порт шлюза | 8765 (порт 8000 давал ошибку EACCES) |
| Привязка шлюза | только 127.0.0.1 |
| Авторизация | API Key: `Authorization: Bearer` или `X-API-Key` |
| Белый список инструментов | `tflex_bridge_ping`, `tflex_active_document`, `tflex_list_variables` |
| Хранение ключа | `%APPDATA%\TFlexMcp\mcp-api-key.dpapi` (DPAPI, учётная запись Windows) |
| Тестовая папка | `D:\dev\TFlex` |
| Тестовый файл | `D:\dev\TFlex\Test\3D Деталь 1.grb` |

## 5. Анализ безопасности исходного проекта

Сильные стороны: мост привязан к localhost, один маршрут `POST /command`, лимит тела 5 МБ, защита от запросов из браузера (проверка Origin, Host, Content-Type), правки идут через `BeginChanges`/`EndChanges` с откатом, `save` по умолчанию выключен.

Риски:

- Нет аутентификации моста: любой локальный процесс пользователя может отправить команду.
- `tflex_execute_csharp` компилирует и выполняет произвольный C# внутри T-FLEX без песочницы. Это удалённое выполнение кода.
- `tflex_bridge_call` пропускает любую сырую команду.
- Пути в `open_document`, `save_as`, `export`, `execute_csharp` не проверяются, каталоги создаются автоматически.
- `gui_*` управляют всем рабочим столом (клики, SendKeys, скриншоты).
- `tflex_launch` принимает произвольный `exePath`.
- Проект молодой (6 коммитов, 2 звезды).

Принятая мера: через внешний коннектор открыты только три инструмента чтения. Фильтр реализован флагами SuperGateway (`--tools`), код проекта не менялся.

## 6. Лаунчер `Start-TFlexMcp.cmd`

Лежит в корне форка. Порядок работы:

1. Проверяет наличие `node`, `npx`, `ngrok`, `mcp\server.js` и работу моста T-FLEX.
2. Останавливается, если порт 8765 занят. Существующие процессы не завершает.
3. При отсутствии файла ключа создаёт его и копирует в буфер обмена (на экран не выводит).
4. Запускает шлюз в отдельном окне. Ключ передаётся через переменную окружения `SUPERGATEWAY_API_KEY`.
5. Проверяет: без ключа 401, с ключом ровно три инструмента.
6. Запускает ngrok или переиспользует проверенный туннель, затем проверяет публичный адрес.

Список инструментов задаётся переменной `$Tools` в начале PowerShell-части. Исправленная ошибка: ключ читается с `.Trim()` (иначе перевод строки в файле ломал `ConvertTo-SecureString`).

Запуск: открыть T-FLEX с плагином и тестовый файл, затем запустить `.cmd`. Окна шлюза и ngrok не закрывать, останавливать через Ctrl+C.

## 7. Подключение в Perplexity

Plugins -> Add custom -> Add MCP connector -> Remote. Адрес `https://aerobics-washer-negotiate.ngrok-free.dev/mcp`, транспорт Streamable HTTP, авторизация API Key. Чтобы вызвать коннектор в запросе, упоминайте его (`@T-FLEX CAD`). Ключ нигде не публикуется. При замене ключа нужно обновить поле в коннекторе.

## 8. Правила работы

- Рабочие файлы T-FLEX не открывать: только копии в `D:\dev\TFlex`.
- Ключ показывать только в поле API Key. При подозрении на утечку пересоздать файл ключа и обновить коннектор.
- Туннель и шлюз держать включёнными только на время работы.
- Выполнение C# и GUI-инструменты через интернет не включать.

## 10. Известные ограничения и открытые вопросы

- Нет подтверждения, что `tflex_active_document` и `tflex_list_variables` показывают структуру модели (эскизы, операции). Чтение сейчас ограничено документом и переменными.
- Имя заголовка, который отправляет Perplexity при авторизации API Key, не выясняли: шлюз принимает оба варианта, соединение работает.
- Бесплатный ngrok: адрес закреплён за аккаунтом, но лимиты и политика тарифа могут меняться.
- Версия T-FLEX 17.1.55 проверена только на чтение.

## 11. Глоссарий

- MCP: Model Context Protocol, протокол подключения инструментов к ИИ.
- Мост: управляемый плагин внутри T-FLEX с HTTP-сервером на localhost.
- Шлюз: SuperGateway, превращает stdio-сервер в HTTP-эндпоинт.
- Белый список: флаги `--tools` шлюза, оставляющие только перечисленные инструменты.
- DPAPI: шифрование Windows, привязанное к учётной записи.
